Hone improves AGENTS.md from sessions that already happened.

No task is re-run.

AGENTS.md: the instruction file a coding agent loads into its system prompt at every session.

@@HERO@@

Reviewers disagree, a judge cross-examines, a verifier gates every edit.

@@SVG@@

A finding survives only if it is grounded in the traces and holds up when the judge questions models that disagree.

1Process signals: a compiler extracts evidence from tool-call sequences.

2Behavior patterns: repeated errors, inefficient tool sequences, format violations.

3Decisions: judges turn the analyses into a review, then one edit set.

Use your agent as usual. Hone edits its AGENTS.md between sessions.

4The next session starts from the new AGENTS.md. Every version stays in Git: compare any two, or roll back.

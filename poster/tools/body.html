Hone improves AGENTS.md from sessions that already happened.

No task is re-run.

AGENTS.md: the instruction file a coding agent loads into its system prompt at every session.

@@HERO@@

Reviewers disagree, a judge cross-examines, a verifier gates every edit.

@@SVG@@

1Trace collection. Sessions arrive as traces with optional feedback; the agent syncs AGENTS.md first.

2Batch assembly. Unanalyzed traces form a frozen batch, fixed for the whole run.

3Review. Reviewers on different models analyze the batch; the judge cross-examines them.

4Propose. Proposers read the report and past decisions; the judge fuses one edit set.

5Verify and commit. Anchor matches once, evidence is in the batch; if not, only propose re-runs.

Mining happens at three points: the trace-evidence compiler extracts process-level signals from tool calls, the review panel extracts recurrent behavioral patterns, and the judge synthesizes these analyses into edit decisions. A hypothesis survives only when it is recurrent in the data and holds up under cross-examination.

Use your agent as usual. Hone edits its AGENTS.md between sessions.
